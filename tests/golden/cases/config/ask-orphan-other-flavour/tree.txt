~ a/personas/d1.env  f 600 inode=same
    | # personas/<name>.env for a Claude persona. ./config-tools writes it from this template; by hand: copy
    | # it, chmod 600, never commit. Comments stay on their own lines: an inline one after an empty value
    | # becomes the value.
    | 
    | # Auth: uncomment ONE of these, or neither and log in inside the persona (`claude`, then follow the
    | # login; it is kept in the persona's home volume). If both are set, the API key wins.
    | # An API key (Console / API billing):
    | # ANTHROPIC_API_KEY=
    | # Or a long-lived subscription token (Pro/Max/Team/Enterprise plan), generated once with `claude setup-token`:
    | # CLAUDE_CODE_OAUTH_TOKEN=
    | 
    | # Commits made by this persona carry this identity.
    | GIT_AUTHOR_NAME=Test User
    | GIT_AUTHOR_EMAIL=test@example.invalid
    | GIT_COMMITTER_NAME=Test User
    | GIT_COMMITTER_EMAIL=test@example.invalid
    | 
    | # Optional.
    | # gh CLI (PRs, issues) and APM (private GitHub packages) as this persona's account:
    | # GH_TOKEN=
    | # Context ddev: never block an unattended run on a ddev prompt:
    | # DDEV_NONINTERACTIVE=true
    | # Default model for this persona:
    | # ANTHROPIC_MODEL=
